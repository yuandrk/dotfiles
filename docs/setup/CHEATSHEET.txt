┌─────────────────────────────────────────────────────────────────────────────┐
│ LINE EDITING  (same keys as bash on Linux)                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ Ctrl-A / Ctrl-E            Start / end of line  (Cmd-Left/Right, Home/End)  │
│ Opt-Left / Opt-Right       Word back / forward  (= Alt-B / Alt-F)           │
│ Ctrl-W                     Delete back to the previous space                │
│ Opt-Backspace              Delete one word back (stops at / . - _)          │
│ Ctrl-U / Ctrl-K            Delete to start / end of line                    │
│ Ctrl-Y                     Paste back what was deleted                      │
│ Ctrl-R                     Search history                                   │
│ Alt-.                      Last argument of the previous command            │
│ Ctrl-X Ctrl-E              Edit the command in nvim                         │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ GHOSTTY  (Cmd-Shift-P lists every action)                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ Cmd-T / Cmd-W              New tab / close        Cmd-1..8   Go to tab      │
│ Cmd-Shift-R                Name the tab                                     │
│ Cmd-D / Cmd-Shift-D        Split right / down                               │
│ Cmd-Alt-arrows             Move between splits    Cmd-[ / ]  Prev / next    │
│ Cmd-Ctrl-arrows            Resize the split       Cmd-Ctrl-= Equalize       │
│ Cmd-Shift-Enter            Zoom the split to the whole tab, and back        │
│ Cmd-Up / Cmd-Down          Jump to the previous / next prompt               │
│ Cmd-F / Cmd-G              Search scrollback / next match                   │
│ Cmd-Shift-S                Open the whole scrollback as a text file         │
│ Cmd-K                      Clear the screen       Cmd-Z      Undo close     │
│ Cmd-`                      Drop-down terminal, from any app                 │
│ Cmd-Shift-,                Reload the config                                │
│                                                                             │
│ Select text = copy. Cmd-click opens a link. A command that ran over 10s     │
│ sends a notification when it ends, if you were looking elsewhere.           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ZMX - SESSIONS THAT SURVIVE CLOSING THE TAB                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│ zmx attach <name>          Attach, creating if needed (prompt: [name])      │
│ Ctrl-\                     Detach - the session keeps running               │
│ zmx ls                     List sessions                                    │
│ zmx kill <name>...         Kill session(s)                                  │
│                                                                             │
│ Scripts / agents (never `attach` from a script):                            │
│ zmx run <name> -d <cmd>    Run in the background, return at once            │
│ zmx wait <name>            Block until done, returns the exit code          │
│ zmx tail <name>            Follow output live                               │
│ zmx history <name> | tail  Read scrollback                                  │
│ zmx send <name> <text>     Type into the session (append \r to run)         │
│                                                                             │
│ GOTCHA: zmx quotes every argument, so 'a; b' arrives as ONE word (127):     │
│   zmx run job -d zsh -c 'a; b'     or     echo 'a; b' | zmx run job         │
└─────────────────────────────────────────────────────────────────────────────┘
